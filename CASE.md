Кейс «Edenguide»
Интерактивная веб-платформа и база знаний для киберспортсменов (VALORANT), обучающая системному мышлению. Проект включает авторскую систему ролей, инструменты для коучинга, административную панель и интеграцию с ИИ-ассистентом.

База знаний: структурированное хранение авторских материалов (тир-листы, система ролей, гайды) с возможностью фильтрации по архетипам (Дайверы, Бравлеры, Поукеры, Универсалы).
Сбор заявок: формы обратной связи и запись на коучинг через веб-интерфейс.
ИИ-ассистент (RAG): интеграция языковой модели для ответов на вопросы пользователей исключительно на основе загруженной базы знаний (без галлюцинаций), а также помощь в разборе игровых ситуаций.
Telegram-интеграция: связка веб-сервиса с Telegram-ботом для моментальных уведомлений о новых заявках и выдачи контента.
Монетизация: авторизация и привязка закрытого контента к подпискам через Boosty API.
Админ-панель: управление контентом, просмотр статистики по входящим заявкам и управление пользователями.
Архитектура: Backend на Python (Flask), работа с БД (SQLite/PostgreSQL), асинхронные запросы к внешним API. Разработка ведется с использованием ИИ-агентов (Opencode) для ускорения написания кода и рефакторинга.
